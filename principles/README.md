# Principles

Short working principles for coding agents. Give an agent the principles that fit its job.

## The files

- There is one file for each principle: `<id>.md`.
- The frontmatter has four fields:
  - `id`: the file name;
  - `name`;
  - `applyWhen`: one line;
  - `source`: the credit.
- The body is 200 words or fewer. It gives the rule, when it applies, when it does not, and when to stop.
